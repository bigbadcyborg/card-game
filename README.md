A self-contained browser app for the goofy tech-themed TCG.

## Features
- Full 30-card gallery with filters
- Card detail modal
- Deck builder (up to 40 cards)
- Rules reference
- Dark neon tech aesthetic

## How to Run
1. Open `index.html` in any modern browser.
2. No server required — fully client-side.

## Files
- `index.html` — Structure
- `styles.css` — Tech neon styling
- `app.js` — Card data + interactivity
